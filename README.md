# SereneChain 产业链拆解挖金

> 一个把任意产业链拆成「挖金地图」的 AI Skill · 覆盖 A股 / 港股 / 美股

## 这是什么

SereneChain 产业链拆解挖金（原名 First 产业链拆解）是一个面向投资研究的 AI 技能（Skill）。你只需输入一个产业名称，它会：

- 🗺️ 自动画出该产业的**上中下游全景图**
- 🔍 用「**高壁垒 · 高利润 · 高增长**」三高标准，圈出最值得看的环节
- 📈 用**边际变化三维模型**（产品结构 / 盈利 / 估值）判断环节是在变好还是变差，提前抓拐点
- 🫧 生成一张**气泡图**，用 ★顶级 / ⚡拐点 / ⚠恶化 标出信号，并列出对应上市公司

它不喊你冲，只帮你把市场喧嚣还原成**结构化、有方法论的视角**。

## 核心方法论

1. **产业链图谱**：AI 构建上中下游结构，联网校验最新动态
2. **三高筛选**：高壁垒 / 高利润 / 高增长，量化打分
3. **边际变化三维评估（Phase 3.5）**：
   - 产品结构边际：是否升级跨阶
   - 盈利边际：良率 / 产能是否破局
   - 估值边际：技术路线是否切换
   - 综合评分 + 方向（↑↑/↑/→/↓）+ 标记（★⚡⚠）
4. **公司深度分析**：财务数据 + 竞争格局 + 边际评估 + 催化时间表
5. **气泡图可视化**：X=壁垒，Y=利润，气泡大小=增长，颜色=上下游

## 如何使用

1. 在支持 Skill 的 Agent（如 WorkBuddy / QClaw）中安装本技能
2. 对话中输入：`（拆解 XX 产业链）`，例如「拆解 存储芯片」
3. 等待技能输出分析报告 + 气泡图
