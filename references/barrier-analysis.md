# 壁垒评估体系

## 一、壁垒类型与评分标准

### 1. 技术壁垒

**定义**：因技术复杂度、专利保护、研发积累形成的进入障碍。

| 评分 | 标准 | 典型特征 |
|------|------|---------|
| 9-10 | 不可逾越 | 垄断性专利、极长研发周期(>10年)、极低成功率(<5%) |
| 7-8 | 高壁垒 | 核心专利保护期长、研发投入巨大、需长期技术积累 |
| 5-6 | 中等壁垒 | 技术有门槛但可攻克、2-3年可突破、需一定研发投入 |
| 3-4 | 低壁垒 | 技术相对成熟、人才流动可带来技术扩散 |
| 1-2 | 几乎无壁垒 | 技术公开成熟、外购即可获得 |

**关键指标**：
- 专利数量与质量（发明专利 vs 实用新型）
- 研发投入占营收比
- 核心技术人员稳定性
- 技术代际差距（领先几代）

**示例**：
- EDA软件：9分（全球仅3家主流厂商，研发积累30+年）
- 光刻机：10分（ASML垄断，极紫外技术门槛极高）
- 普通注塑件：2分（技术成熟，供应商众多）

### 2. 资源壁垒

**定义**：因稀缺资源掌控形成的进入障碍。

| 评分 | 标准 | 典型特征 |
|------|------|---------|
| 9-10 | 资源独占 | 独占矿产资源、独家牌照、唯一供应商 |
| 7-8 | 资源稀缺 | 掌握优质资源、稀缺矿权、特许经营权 |
| 5-6 | 资源受限 | 资源可获取但成本高、周期长 |
| 3-4 | 资源一般 | 资源可通过市场获取 |
| 1-2 | 无资源壁垒 | 资源充裕、完全市场化 |

**关键指标**：
- 资源自给率
- 资源品位（矿石品位、矿区质量）
- 资源获取成本（对比行业均值）
- 特许经营/牌照有效期

**示例**：
- 赣锋锂业优质锂矿：8分（优质锂矿资源稀缺）
- 核电牌照：10分（仅中核/中广核/国电投持有）
- 普通钢铁：3分（铁矿石全球可贸易）

### 3. 规模壁垒

**定义**：因规模经济效应形成的进入障碍。

| 评分 | 标准 | 典型特征 |
|------|------|---------|
| 9-10 | 极高规模效应 | 最低经济规模巨大(>百亿)、规模成本优势>30% |
| 7-8 | 显著规模效应 | 规模优势明显(15-30%成本差距)、后进者难以追赶 |
| 5-6 | 中等规模效应 | 规模有一定优势但非决定性(5-15%成本差距) |
| 3-4 | 弱规模效应 | 规模优势有限(<5%)、小而美也可存活 |
| 1-2 | 无规模效应 | 规模不构成优势、定制化为主 |

**关键指标**：
- 行业最低经济规模
- 头部企业产能规模
- 单位成本曲线（随产量下降的幅度）
- 资本开支门槛

**示例**：
- 晶圆代工（先进制程）：10分（单座晶圆厂投资>150亿美元）
- 光伏硅料：7分（万吨级产线投资大，成本优势显著）
- 餐饮：2分（单店模型，规模效应弱）

### 4. 品牌/客户壁垒

**定义**：因品牌认知、客户粘性、转换成本形成的进入障碍。

| 评分 | 标准 | 典型特征 |
|------|------|---------|
| 9-10 | 极高粘性 | 客户转换成本极高、认证周期>3年、品牌不可替代 |
| 7-8 | 高粘性 | 客户粘性强、认证周期1-3年、品牌溢价明显 |
| 5-6 | 中等粘性 | 有一定转换成本、认证周期6-12个月 |
| 3-4 | 低粘性 | 转换成本较低、客户多供应商策略 |
| 1-2 | 无粘性 | 标准化产品、即插即用 |

**关键指标**：
- 客户认证周期
- 客户留存率
- 前五大客户收入占比
- 供应商替代难度

**示例**：
- 航发叶片供应商：9分（认证周期5+年，零容错）
- 苹果供应链：7分（认证严格但存在替换风险）
- 标准紧固件：2分（无认证门槛）

### 5. 网络效应壁垒

**定义**：因用户规模/生态网络形成的自我增强型进入障碍。

| 评分 | 标准 | 典型特征 |
|------|------|---------|
| 9-10 | 强网络效应 | 用户越多价值越大、赢家通吃、转移成本随规模递增 |
| 7-8 | 显著网络效应 | 双边/多边网络效应、生态粘性强 |
| 5-6 | 中等网络效应 | 有一定网络效应但非核心驱动力 |
| 3-4 | 弱网络效应 | 网络效应有限、垂直/细分领域可切入 |
| 1-2 | 无网络效应 | 无网络效应、产品价值独立于用户规模 |

**示例**：
- 微信支付：10分（12亿用户网络效应）
- AutoCAD：8分（行业标准格式锁定）
- 普通SaaS：5分（有一定粘性但可替换）

## 二、综合壁垒评分方法

### 加权评分公式

```
综合壁垒 = 0.30 × 技术壁垒 + 0.25 × 资源壁垒 + 0.20 × 规模壁垒 + 0.15 × 品牌/客户壁垒 + 0.10 × 网络效应壁垒
```

### 权重调整规则

根据产业类型调整权重：

| 产业类型 | 技术 | 资源 | 规模 | 品牌/客户 | 网络效应 |
|---------|------|------|------|----------|---------|
| 资源驱动型 | 0.15 | 0.40 | 0.15 | 0.20 | 0.10 |
| 技术驱动型 | 0.45 | 0.10 | 0.15 | 0.20 | 0.10 |
| 品牌驱动型 | 0.10 | 0.10 | 0.15 | 0.45 | 0.20 |
| 规模驱动型 | 0.15 | 0.10 | 0.40 | 0.20 | 0.15 |
| 网络驱动型 | 0.20 | 0.05 | 0.10 | 0.20 | 0.45 |

### 壁垒评分校验

打分后需通过以下校验：
1. **替代品测试**：如果出现替代品，壁垒是否仍然有效？
2. **时间测试**：5年后该壁垒是否仍然存在？
3. **政策测试**：政策变化是否会消除该壁垒？
4. **资本测试**：大量资本能否快速突破该壁垒？

如果任一校验不通过，需下调评分1-3分。

## 三、壁垒动态变化

壁垒不是静态的，需关注以下变化趋势：

- **壁垒上升**：技术迭代加速→领先者差距拉大；行业出清→集中度提升
- **壁垒下降**：专利到期→技术扩散；国产替代→供给增加；政策开放→牌照贬值
- **新壁垒形成**：技术路线切换→先发优势；数据积累→算法壁垒

**实战要点**：分析壁垒时需同时判断壁垒的趋势方向，上升中的壁垒更具投资价值。
