# 产业链分析框架方法论

## 一、产业链本质

产业链是**价值创造与分配的链条**。每个环节都在完成特定的价值增值活动，但增值的幅度和持续性差异巨大。

**核心规律**：
- 价值分配不均：少数环节攫取大部分利润（微笑曲线）
- 利润向壁垒最高的环节集中
- 供需失衡时，供给受限环节获得超额利润
- 技术变革会重构产业链价值分配

## 二、产业链拆解方法论

### 2.1 拆解原则

1. **按价值链拆，不按企业拆**：先定环节，再找企业
2. **至少拆到三级**：
   - 一级：上游/中游/下游
   - 二级：核心产品/部件类别
   - 三级：细分材料/工艺/应用场景
3. **关键环节单列**：瓶颈环节、高价值环节需单独列出

### 2.2 上游识别要点

上游通常包含：
- **基础原材料**：矿产资源、化工原料、金属材料
- **核心零部件**：芯片、传感器、电机、阀门
- **生产设备**：制造设备、检测设备、加工设备
- **基础软件/IP**：EDA工具、设计IP、核心算法

上游分析关键词：**资源禀赋、技术门槛、供给弹性、国产化率**

### 2.3 中游识别要点

中游通常包含：
- **加工制造**：组装、封装、系统集成
- **核心模块**：动力总成、显示模组、电池Pack
- **品牌商/方案商**：品牌运营、解决方案

中游分析关键词：**规模效应、成本优势、客户粘性、品牌溢价**

### 2.4 下游识别要点

下游通常包含：
- **终端产品**：整车、手机、家电、医疗设备
- **应用服务**：运营维护、增值服务、数据服务
- **渠道/零售**：经销体系、终端门店

下游分析关键词：**需求弹性、消费趋势、渠道控制力、复购属性**

## 三、供需分析框架

### 3.1 供给端分析维度

| 维度 | 分析要点 | 判断方法 |
|------|---------|---------|
| 供给集中度 | CR3/CR5市占率 | >60%为高集中度 |
| 产能周期 | 扩产节奏 vs 需求增速 | 产能利用率>85%为偏紧 |
| 进入壁垒 | 新进入者需要多久/多少钱 | 参考 barrier-analysis.md |
| 供给弹性 | 短期能否快速扩产 | 资本密集型弹性低 |
| 进口依赖 | 国产替代空间 | 进口占比>30%有替代空间 |

### 3.2 需求端分析维度

| 维度 | 分析要点 | 判断方法 |
|------|---------|---------|
| 需求驱动 | 政策/技术/消费/出口 | 多重驱动>单一驱动 |
| 需求增速 | 行业CAGR | >15%为高增长 |
| 需求持续性 | 渗透率阶段 | 10-40%为快速渗透期 |
| 替代风险 | 新技术替代可能性 | 颠覆式/渐进式 |
| 客户集中度 | 下游客户CR5 | >50%为高集中度 |

### 3.3 供需状态判定矩阵

```
          需求高增        需求平稳        需求萎缩
供给受限  ★★★★★         ★★★★          ★★★
        （最佳投资机会）  （利润稳定）    （存量博弈）
供给平衡  ★★★★          ★★★           ★★
        （成长机会）     （周期波动）    （红海竞争）
供给过剩  ★★★           ★★            ★
        （量增价跌）     （价格战）     （加速出清）
```

## 四、产业链思维模型

### 4.1 微笑曲线

```
利润
  ↑
  │    研发/设计              品牌/服务
  │      ↗                      ↖
  │    /                          \
  │   /                            \
  │  /                              \
  │ /                                \
  │/          制造/组装               \
  └────────────────────────────────────→ 价值链环节
```

**应用**：寻找曲线两端的环节（高附加值），规避中间洼地。

### 4.2 产业链"卡脖子"识别法

卡脖子环节的六大特征：
1. **国产化率低**（<30%）
2. **全球供给集中**（CR3 > 60%）
3. **认证周期长**（> 2年）
4. **资本开支大**（重资产）
5. **技术迭代慢**（不频繁更新，但壁垒高）
6. **下游议价弱**（不可替代）

### 4.3 产业链价值迁移模型

价值在产业链中的分布不是静态的，会随以下因素迁移：
- **技术变革**：新技术环节崛起，旧环节衰落
- **政策推动**：补贴/限制改变利润分配
- **产能周期**：扩产高峰→供给过剩→利润向下游转移
- **国产替代**：替代初期利润高，替代完成利润回归均值

**实战应用**：分析时需判断当前处于哪个阶段，预判利润流向。

## 五、常见产业链模式

### 5.1 资源驱动型（如锂电、稀土）
- 利润核心在上游资源端
- 价格周期性强
- 关注资源自给率

### 5.2 技术驱动型（如半导体、创新药）
- 利润核心在技术突破环节
- 研发投入是核心指标
- 关注技术路线选择

### 5.3 品牌驱动型（如白酒、化妆品）
- 利润核心在品牌/渠道端
- 品牌溢价是护城河
- 关注品牌力与复购率

### 5.4 规模驱动型（如光伏、面板）
- 利润核心在成本领先者
- 规模效应是关键
- 关注成本曲线位置

### 5.5 网络驱动型（如互联网平台、支付）
- 利润核心在网络效应强的平台
- 用户规模是核心指标
- 关注用户粘性与变现效率
